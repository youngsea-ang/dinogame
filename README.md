## 🎮 게임 소개

파이썬과 Pygame을 이용해 만든 공룡 점프 게임입니다.

## 🕹️ 조작법

- `SPACE` / `↑` : 점프
- `↓` : 숙이기
- 장애물을 피하면서 최대 점수를 기록하세요!

## ✨ 주요 기능

- 🦖 공룡 달리기 애니메이션
- 🌵 선인장 장애물
- 🦅 익룡 장애물
- ☁️ 움직이는 구름
- 🔊 점프 / 사망 / 점수 효과음
